# 🔐 You Private 2FA Authenticator

Локальный, абсолютно приватный и автономный генератор кодов двухфакторной аутентификации (TOTP) в виде расширения для Google Chrome (Manifest V3).

---

## ✨ Особенности проекта

* **0 зависимостей:** Код написан на чистом JavaScript и HTML/CSS без использования внешних библиотек (никаких JQuery, Bootstrap или внешних крипто-пакетов).
* **Полный офлайн:** Расширение не делает ни одного сетевого запроса. Коды генерируются прямо на вашем процессоре с помощью встроенного в браузер движка веб-криптографии `crypto.subtle`.
* **Безопасное хранение:** Секретные ключи хранятся внутри изолированного локального хранилища браузера (`chrome.storage.local`) и никогда не покидают ваш ПК.
* **Кастомный UI:** Стильный и лаконичный интерфейс в темных тонах с полосой обратного отсчета времени действия кода (30 секунд) и автоматическим обновлением.
* **Удобство:** Код можно выделить и скопировать в один клик.

---

## 🚀 Как установить расширение (Локально)

Поскольку это приватное расширение, его нет в Chrome Web Store (и это гарантирует, что код не обновится на вредоносный без вашего ведома). Установка занимает меньше минуты:

1. Скачайте этот репозиторий в виде ZIP-архива и распакуйте его (или склонируйте с помощью `git clone`).
2. Откройте браузер Chrome и перейдите на страницу расширений: `chrome://extensions/`.
3. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
4. В левом верхнем углу нажмите появившуюся кнопку **«Загрузить распакованное расширение»** (Load unpacked).
5. Выберите папку, в которую вы распаковали файлы проекта.

*Всё! Иконка расширения появится на вашей панели инструментов.*

---

## 🛠️ Как им пользоваться

1. **Добавление ключей:** Нажмите правой кнопкой мыши по иконке расширения в панели Chrome и выберите **«Параметры»** (Options). Откроется удобная страница настроек.
2. Введите название сервиса (например, `GitHub-Work`) и ваш секретный ключ в формате Base32 (строка из букв и цифр, которую выдает сайт при привязке 2FA). Нажмите **«Сохранить аккаунт»**.
3. **Просмотр кодов:** Просто кликните левой кнопкой мыши по иконке расширения на панели браузера. Коды обновляются каждую секунду, а при клике на сам код он выделяется целиком для быстрого копирования.

## 🔒 Дисклеймер безопасности

Перенос 2FA на компьютер повышает удобство, но снижает фактор «изоляции». Если ваш компьютер будет заражен вредоносным ПО (стилером), злоумышленник может получить доступ как к вашим паролям, так и к хранилищу этого расширения. 

**Рекомендация:** Используйте данное расширение на защищенных рабочих машинах и не храните секретные ключи в открытом текстовом виде.
